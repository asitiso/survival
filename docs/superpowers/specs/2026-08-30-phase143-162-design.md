# Phase 143-162 Combat Finish Design

## Goal
Finish late-game combat feel and landscape-mobile polish without adding combat actions or blocking menus.

## Constraints
- Keep exactly nine combat actions.
- Preserve Phase 142 snapshot compatibility.
- Prefer transient/runtime-only state over new persisted schema.
- Do not reduce enemy AI pressure to solve rendering or fatigue issues.
- Existing telegraphs remain readable at every presentation tier.

## Phase 143-146 — Boss Arena Physical Geometry
Boss arena hazards use shape-aware collision instead of a circle for every geometry. Ring/orbit use annulus checks, corridor/cross use oriented capsules/lanes, pockets use circles, and clock uses radial wedges. Collision returns damage plus a bounded displacement/slow response so the arena shape changes movement decisions rather than only visuals.

## Phase 147-150 — Final Form Flow Feedback
Flow streak thresholds produce small, throttled combat cues and a hero aura/trail profile. The cue reflects mobility family and streak but creates no persistent projectile system. Rendering scales with presentation quality and long-run comfort.

## Phase 151-154 — Opening Wave Ceremony
The first ten minutes receive deterministic non-blocking wave beats at 30s, 120s, 300s, and 540s. Each beat provides a short pressure/reward pulse and a concise toast. It composes with OpeningPacing and returns to neutral after a few seconds.

## Phase 155-158 — Landscape Safe Area Profiles
Landscape HUD/input derives logical safe insets from viewport aspect ratio. 16:9 remains almost unchanged; 19.5:9/20:9 protects side gesture/cutout zones; 4:3 protects vertical HUD space. Joystick start and status width use the same profile.

## Phase 159-162 — Browser Visual Regression Harness
Expose a deterministic presentation probe for key landscape states and provide a browser smoke page/query mode that can render stable snapshots without changing normal gameplay. Automated tests verify probe contracts; final verification attempts a real headless browser screenshot and falls back transparently to DOM/HTTP evidence if the container browser is unavailable.

## Integration
- `BossArenaSystem` owns shape-aware collision.
- `Game` composes arena response, opening pulse, Flow feedback, and safe-area HUD context.
- `InputState` consumes safe-area profile without new actions.
- Snapshot schema stays unchanged for transient Flow/wave/viewport data.
