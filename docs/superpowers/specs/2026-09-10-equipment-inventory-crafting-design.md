# 장비 인벤토리·강화·조합 설계

## 목표

금화를 모으고 장비를 선택하는 과정이 실제 생존력 차이로 이어지게 한다. 플레이어는 상점 한 화면에서 구매, 장착, 강화, 조합, 판매를 처리하며 현재 무엇이 부족한지 바로 이해할 수 있어야 한다. 별도 재화와 별도 로비 화면은 추가하지 않는다.

## 플레이 흐름

상점에는 `구매`와 `대장간` 두 탭을 둔다. 첫 장비를 구입했을 때 해당 장착 슬롯이 비어 있으면 즉시 장착한다. 이미 슬롯이 차 있거나 같은 종류의 다른 장비를 구입하면 장비는 6칸 보관함에 저장한다. 같은 장비는 한 칸에 수량으로 쌓아 불필요한 칸 정리를 줄인다.

대장간 상단에는 무기, 방어구, 장신구 장착 슬롯과 6칸 보관함을 함께 표시한다. 보관 장비를 선택하면 장착, 강화, 조합, 판매 중 가능한 행동만 활성화한다. 끌어놓기는 사용하지 않고 클릭과 버튼만 사용한다. 장착 중인 장비는 조합 재료로 자동 선택하거나 소모하지 않는다.

보관함에 새로운 종류를 넣을 빈 칸이 없으면 구매 버튼을 비활성화하고 `보관함이 가득 찼습니다 · 장비 판매 또는 조합 필요`를 표시한다. 이미 보관 중인 같은 장비는 수량이 쌓이므로 계속 구매할 수 있다.

## 데이터 구조

`EquipmentState`에 다음 데이터를 추가한다.

- `inventory`: 최대 6종의 장비 스택. 각 스택은 장비 ID, 종류, 이름, 등급, 능력치, 수량을 가진다.
- `discoveredRecipes`: 현재 실행에서 발견한 히든 조합 ID 목록.

히든 조합의 영구 발견 상태는 메타 프로필에 별도로 저장한다. 실행 스냅샷에는 보관함과 현재 실행 발견 상태를 저장한다. 과거 스냅샷에는 두 필드가 없으므로 빈 배열을 기본값으로 사용한다. 알 수 없는 장비·조합 ID, 음수 수량, 6종 초과 데이터는 저장 정화 단계에서 거부하거나 경계값으로 제한한다.

장비 스택은 같은 ID와 같은 등급만 합친다. 서로 다른 등급은 별도 스택으로 취급한다. 제작 결과를 넣을 공간은 소비될 재료 칸까지 포함해 거래 전에 계산한다.

## 구매와 판매

금화는 구매, 강화, 조합에 공통으로 사용한다. 새 재화나 제작 조각은 추가하지 않는다.

- 빈 슬롯의 첫 장비: 구매 후 자동 장착
- 장착 슬롯이 찬 상태의 장비: 보관함에 저장
- 같은 ID·등급의 보관 장비: 기존 스택 수량 증가
- 판매: 장비 기본 구매가의 35%를 환급

구매 전에는 금화, 등급 해금 시간, 보관 공간을 모두 검사한다. 하나라도 충족하지 않으면 상태를 전혀 변경하지 않는다. 구매 추천은 현재 영웅 유효 체력, 수호핵 방어, 화력 지수, 보관함 상태를 사용한다.

## 강화

강화는 장착 장비 또는 선택한 보관 장비를 대상으로 하며, 같은 ID의 보관 장비와 금화를 소비한다.

|강화|같은 장비 재료|금화|
|---|---:|---:|
|일반 → 고급|1개|150G|
|고급 → 희귀|1개|350G|
|희귀 → 영웅|2개|800G|
|영웅 → 전설|2개|1,800G|
|전설 +N|1개|직전 비용 ×1.32, 상한 적용|

기존 등급 해금 시각인 1분 30초, 4분, 8분, 12분과 전설 이후 2분 간격을 유지한다. 강화 결과는 기존 장비의 ID와 슬롯을 유지하고 랭크만 올린다. 비용과 재료가 충분하지 않으면 아무것도 소비하지 않는다.

## 일반 조합

일반 조합은 고급 이상 장비 두 개와 금화를 소비해 같은 슬롯의 희귀 조합 장비를 만든다.

|재료|결과|비용|핵심 효과|
|---|---|---:|---|
|마력 지팡이 + 속사 완드|비전 가속봉|700G|마법 피해·쿨타임|
|폭발 지팡이 + 황금 완드|연금 폭발봉|650G|범위·금화 획득|
|철갑 로브 + 질풍 망토|바람 철갑|750G|영웅 피해 감소·이동속도|
|자석 망토 + 수호 갑주|중력 수호갑|800G|수집 범위·수호핵 피해 감소|
|현자의 부적 + 폭풍 반지|현뢰의 인장|600G|마법 피해·쿨타임|
|성채의 성표 + 행운의 펜던트|황금 성채 부적|650G|영웅 피해 감소·금화 획득|

결과 장비는 랭크 3으로 시작한다. 일반 조합식은 처음부터 이름, 재료, 최소 등급, 금화, 결과 능력치와 예상 생존 변화를 모두 표시한다.

## 히든 조합

히든 조합은 희귀 일반 조합 장비 두 개와 금화를 소비해 전설 등급 장비를 만든다.

|재료|결과|비용|핵심 효과|
|---|---|---:|---|
|비전 가속봉 + 연금 폭발봉|천체 융합봉|2,800G|마법 피해·범위·쿨타임|
|바람 철갑 + 중력 수호갑|세계수 성갑|3,200G|영웅·수호핵 피해 감소·이동속도|
|현뢰의 인장 + 황금 성채 부적|운명의 핵|2,500G|마법 피해·쿨타임·금화·피해 감소|

히든 조합은 재료를 하나도 얻지 않았을 때 목록에 표시하지 않는다. 재료 하나를 얻으면 결과 이름과 정확한 수치를 감춘 힌트 카드를 표시한다. 재료 둘을 모두 보관함에 넣으면 제작 버튼이 활성화되지만 제작 전까지 결과 이름은 `???`로 유지한다. 최초 제작 후 결과 이름, 조합식, 효과를 메타 프로필에 영구 공개한다.

천체 융합봉, 세계수 성갑, 운명의 핵을 모두 장착하면 `창세의 유산` 히든 세트가 발동한다. 효과는 마법 피해 +35%, 쿨타임 -12%, 영웅과 수호핵이 받는 피해 -22%로 구성한다. 모든 배율은 기존 장비 보너스 합성 경로에서 한 번만 적용한다.

## 설명과 생존 피드백

장비 카드에는 다음 정보를 고정된 순서로 표시한다.

1. 현재 등급과 슬롯
2. 기본 효과
3. 강화 재료와 금화
4. 일반 조합 재료 또는 히든 힌트
5. 구매·강화·조합 후 생존 변화

생존 변화는 현재 시간대의 일반 적 접촉 피해를 기준으로 계산한다. 영웅 예상 생존 타수, 수호핵 피해 배율, 화력 지수를 함께 보여준다. 단일 퍼센트 점수로 모든 상황을 숨기지 않는다.

상점 상단의 장비 준비도는 다음 규칙으로 표시한다.

- `준비 부족`: 현재 시간 권장치보다 영웅 생존 타수 또는 화력 지수가 20% 이상 낮음
- `생존 가능`: 두 지표가 권장치의 80~120%
- `안정`: 두 지표가 권장치의 120% 이상이며 수호핵 피해 배율도 권장 범위 충족

추천 문구는 부족한 지표 하나와 개선 폭을 제시한다. 예: `영웅 생존 부족 · 바람 철갑 장착 시 약 4타 증가`. 보관함 정리나 조합이 필요한 경우 구매 추천보다 먼저 표시한다.

## 밸런스 목표

적 난이도는 플레이어 장비에 따라 동적으로 증가시키지 않는다. 장비를 사면 얻은 이득이 그대로 남도록 시간 기반 적 압력을 유지한다.

- 5분: 희귀 장비 1~2개 또는 고급 장비 2세트 준비
- 8분: 희귀 2세트와 최소 방어 장비 1개 권장
- 12분: 전설 또는 일반 조합 장비 1개 권장
- 15분: 일반 조합 장비 2개 또는 히든 조합 장비 1개 권장
- 20분 이후: 전설 추가 강화와 히든 세트가 금화 소비처 역할

보수적 금화 회수율 25%에서도 권장 단계의 핵심 방어 장비를 살 수 있어야 한다. 45% 회수에서는 공격·금화 장비나 히든 조합을 추가로 선택할 수 있어야 한다. 무장하지 않은 상태는 8분 이후 생존 타수와 처치 속도에서 권장 장비보다 뚜렷하게 불리해야 한다.

## 거래 안전성과 오류 처리

구매, 강화, 조합, 판매는 모두 순수 상태 전이 함수로 구현한다. 각 함수는 입력 상태를 복제하고 모든 조건을 먼저 검사한 뒤 한 번에 결과를 반환한다.

- 장착 장비 자동 소비 금지
- 재료 부족, 금화 부족, 해금 시간 미달, 보관 공간 부족 시 무변경
- 중복 클릭이 발생해도 한 번의 호출당 한 번만 거래
- 제작 결과와 발견 상태는 동일 거래에서 함께 반영
- 알 수 없는 조합 ID는 실패 처리

빠른 구매는 보관 공간과 활성 세트 해제를 함께 검사한다. 조합 장비를 추천할 수는 있지만 자동 제작은 하지 않는다.

## 테스트와 검증

구현은 실패하는 테스트부터 작성한다.

- 6종 보관 제한과 동일 스택 수량 증가
- 빈 슬롯 자동 장착과 찬 슬롯 보관
- 강화 재료·금화·시간 조건 및 실패 시 무변경
- 일반 조합 6종과 히든 조합 3종의 정확한 소비·결과
- 장착 장비가 자동으로 재료가 되지 않는 조건
- 히든 힌트, 최초 발견, 영구 공개
- 창세의 유산 배율이 한 번만 적용되는 조건
- 구버전 저장 복원과 손상된 인벤토리 정화
- 빠른 구매의 보관함·세트 보호
- 5·8·12·15·20분의 보수적 금화 예산과 장비 준비도
- 구매 전후 영웅 생존 타수, 수호핵 피해, 화력 지수 변화

타입 검사와 전체 테스트를 실행한 뒤 실제 상점 화면에서 모바일 크기, 탭 전환, 6칸 보관함, 조합 설명, 히든 공개 상태를 확인한다.
