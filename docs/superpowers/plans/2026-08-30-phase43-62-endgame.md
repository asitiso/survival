# Phase 43~62 Endgame Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Phase 42 본체에 80분 이후 최종형, 자동 Overdrive, Mythic 3페이즈, 같은 조건 재도전, 복구 저널, 8시간 안정성 검증을 추가한다.

**Architecture:** 순수 장기런 규칙은 `src/game/endless/`, 로컬 영속성은 `src/domain/`에 분리한다. `game.ts`는 기존 9 Action과 선택 UI를 유지하면서 modifiers/effects/persistence만 연결한다.

**Tech Stack:** TypeScript ES modules, Node test runner, DOM UI, localStorage-compatible SnapshotStorage.

**Spec:** `docs/superpowers/specs/2026-08-30-phase43-62-endgame-design.md`

## Global Constraints
- 전투 Action은 9개를 유지한다.
- 새 선택 모달을 추가하지 않는다.
- Snapshot은 적/탄막 좌표 배열을 저장하지 않는다.
- legacy snapshot/history를 계속 읽는다.
- Ascension X 이후 수치 배율 상한을 유지한다.
- 저사양에서는 표현 밀도를 전투 판정보다 먼저 줄인다.
