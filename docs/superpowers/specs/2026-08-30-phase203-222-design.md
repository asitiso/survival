# Phase 203~222 Design

## Goal
Polish high-skill Mythic play and landscape mobile presentation without adding combat actions, blocking modals, or persistent snapshot burden.

## Product constraints
- Keep exactly 9 combat actions: four normal spells, two ultimates, potion, shop, AUTO.
- New systems are automatic, movement-driven, or presentation-only.
- Do not add raw enemy/projectile coordinates to snapshots.
- Preserve existing 16:9, 20:9, 4:3, foldable, and 32:9 behavior.
- Prefer bounded transient state over new persistence fields.

## Phase 203~206 — Perfect Evade Finisher
Reaching evade chain x5 for the first time in a chain triggers one bounded automatic shockwave. Extra evades while already capped at x5 do not retrigger it. The finisher deals bounded nearby damage, push/slow, provides a small Signature bonus, and has no gold/XP reward.

## Phase 207~210 — Safe Lane Link
Reaching the current SAFE LANE target arms a short link window. If the player earns PERFECT EVADE while armed and has a Final Form, the current mobility family converts the success into a bounded Flow/Signature/movement reward. The system never auto-moves the hero and expires quickly if no evade occurs.

## Phase 211~214 — Mythic Safe Zone Lifecycle
Each Mythic archetype gets deterministic safe-zone phases: stable, collapse warning, collapsed, and reform. Safe-zone placement moves in a boss-specific sequence. SAFE LANE scoring can prefer the currently stable zone, but collision safety remains authoritative. The lifecycle is derived from encounter time and archetype, so it needs no snapshot field.

## Phase 215~218 — Foldable Density Director
Foldable presentation dynamically allocates information density between the left hero/build panel and right status panel. Mythic/boss pressure reduces detail before hiding critical information. Standard aspect classes remain unchanged. This is presentation policy only.

## Phase 219~222 — Raster Baseline Gate
Add a deterministic baseline gate on top of the existing primitive and raster contracts. It records signatures, global similarity thresholds, and critical-cell similarity thresholds for five representative landscape classes. Intentional visual changes require an explicit baseline update; accidental drift fails tests.

## Verification
- TDD for each subsystem.
- New phase integration tests assert no new actions and no snapshot schema additions.
- Full regression suite must pass.
- TypeScript build and git diff check must pass.
- Static HTTP smoke must return 200 for core modules.
- Render contract + raster baseline audit must pass across 16:9, 20:9, 4:3, foldable, and 32:9.
