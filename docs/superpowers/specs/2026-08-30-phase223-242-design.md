# Phase 223-242 Design

## Goal
Polish the existing Phase 203-222 skill loop without adding combat actions, blocking menus, or persistent snapshot schema. The player should feel a stronger payoff for mastered evasions, get clearer safe-lane timing, see Mythic attacks synchronize with safe-zone lifecycle, receive better foldable touch ergonomics, and gain an auditable render-baseline workflow.

## Global constraints
- Keep exactly 9 combat actions: 4 normal spells, 2 ultimates, potion, shop, AUTO.
- Add no blocking combat modal and no new management menu.
- Add no new Run Snapshot schema field for these transient systems.
- Mythic collision geometry remains the authority for danger/safety decisions.
- Foldable behavior must not alter 16:9, 20:9, 4:3 or 32:9 layouts.
- Raster baseline changes must fail closed until explicitly approved.

## Phase 223-226 — Final Form Evade Finish Identity
The existing PERFECT EVADE x5 finisher becomes Final-Form-aware. The 12 final forms map through their existing mobility/pattern identity into four bounded finisher families: execution, chain, control, and bulwark. The finisher remains automatic and one-shot on first x5 entry. It may vary radius/damage/push/slow/chain/core recovery, but must remain within strict caps and must not award gold or XP.

## Phase 227-230 — Safe Lane Forecast
SAFE LANE gains a short forecast path rather than only a destination. A deterministic forecast produces current target, next target, transition timing, and urgency from the active safe-zone lifecycle plus arena hazards. It never moves the hero. Stable/reform states receive lower urgency; collapse/collapsed states receive stronger visual urgency. The existing safe-link arming logic continues to require physical arrival.

## Phase 231-234 — Mythic Attack / Safe-Zone Synchronization
Mythic pressure multipliers are synchronized to the safe-zone phase. Stable phases bias toward readable pressure, collapse phases ramp, collapsed phases peak, and reform phases briefly release pressure. The effect is bounded and archetype-aware, composed on top of existing Mythic identity/Last Law modifiers rather than replacing them. Destroyed weakpoints still reduce pressure.

## Phase 235-238 — Foldable Touch Density Director
On foldables only, action hit regions are adaptively compressed away from the hinge and from each other while preserving the same 9 action IDs and visual button locations. Touch hit radii may be reduced slightly for crowded right-side clusters, and selection remains nearest-normalized-distance. Joystick start exclusion continues to use the same safe-area profile. Non-foldable hit testing is unchanged.

## Phase 239-242 — Raster Baseline Approval & Report
Build a baseline comparison report over all five representative landscape classes. The report records expected/current signatures, overall and critical similarity, changed cell counts, and a deterministic change token. Baseline updates require an explicit approval token matching the current report; without it, changed signatures remain a failure. No automatic baseline rewrite is allowed.

## Integration seams
- `src/game/game.ts`: consume form-aware evade finisher, safe-lane forecast, safe-zone attack synchronization, and foldable touch density state only at existing update/render seams.
- `src/core/input.ts` and `src/core/touch-controls.ts`: accept optional adaptive hit profiles without changing Action IDs.
- `src/game/render-raster-baseline.ts` and new report module: expose comparison/approval APIs for tests/CI.
- `src/game/endless/snapshot.ts`: unchanged for the new transient systems.

- TypeScript build and `git diff --check`.
- Render/Raster audit for 16:9, 20:9, 4:3, foldable, and 32:9.
