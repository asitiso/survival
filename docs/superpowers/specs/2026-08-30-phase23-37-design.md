# Phase 23–37 Integrated Design

## Goal
Merge Phase 23–27 into the real Phase 22 game without increasing the nine combat actions, then extend the endless game through 180+ minutes with hero-specific late-game identity, boss-space mutation, mythic escalation, deterministic recovery, and clearer run records.

## Constraints
- Keep combat actions fixed: normal spells 4 + ultimates 2 + potion + shop + AUTO.
- Reuse `LevelUpOverlay` for any new three-choice modal.
- New systems must be snapshot-safe and deterministic where practical.
- Never persist enemy/projectile coordinates in run snapshots.
- Prefer modifiers/effects and existing render/update channels over new global managers.
- Tiered numeric scaling must cap; after cap, variety comes from patterns/mutators instead of unbounded multipliers.
- Mobile performance degrades visuals before enemy logic.

## Architecture
Phase 23–27 lives under `src/game/endless/` and exposes a single `advanceEndlessRuntime()` orchestrator. `Game` owns host state and converts combat events into a small event array once per frame. `RunSnapshot` embeds a compact serialized extension string and migrates old snapshots.

Phase 28–37 adds focused modules that consume the same compact runtime state:
1. Boss arena mutations per archetype and late tier.
2. Hero ascension choices at late-run milestones, capped at three selections.
3. Relic resonance from existing relic/fusion/fate state; no extra inventory UI.
4. Adaptive pressure stabilizer to prevent object-count spikes while preserving difficulty through composition.
5. Mythic boss rules after 60 minutes using 2–3 existing channels, never mass enemy duplication.
6. Chronicle milestones for 45/60/90/120/180 minute recognition.
7. Compact final-build code and run fingerprints for result/history comparison.
8. Snapshot integrity checksum plus tolerant migration.
9. Long-run simulator checkpoints through 180 minutes and Threat 5 low-device guards.
10. HUD summary remains within existing compressed information budget; deep details stay in pause/result copy.

## Data flow
`Game.update` gathers events → `advanceEndlessRuntime` updates telemetry/contracts/world/nemesis/ascension/late systems → declarative effects route back through existing stats, toasts, overlay, boss/spawn configuration and render layers.

## Testing
All feature behavior is introduced through Node tests against compiled `dist`. Full 343-test baseline must remain green, then new tests cover deterministic restoration, contract timing, world catch-up, nemesis memory, ascension cap, arena mutation, hero ascension, mythic rules, adaptive pressure, snapshot migration/checksum, 180-minute balance, and no-new-action invariant.
