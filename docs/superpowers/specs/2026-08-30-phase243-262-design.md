# Phase 243~262 Combat Polish Design

## Goal
Phase 242의 고숙련 Mythic 전투를 새 버튼이나 저장 상태 증가 없이 더 읽기 쉽고 손맛 있게 마감한다.

## Global constraints
- Combat actions remain exactly 9.
- No blocking modal or new management menu.
- No new snapshot field for Phase 243~262 transient state.
- Existing Mythic geometry/collision remains the authority for safe-space correctness.
- Non-foldable touch behavior remains byte-for-byte equivalent at the call seam: `hitTestActionButton(p)`.
- Raster baseline files/signatures are never rewritten automatically.

## Phase 243~246 — Final Form Finisher Feedback
Create `src/game/endless/final-form-finisher-feedback.ts`.

The four existing Final Form evade-finisher families receive distinct presentation profiles:
- execution: warm gold, tight double ring, strongest shake, low particle count, `finisherExecution` sound.
- chain: cyan, radial spokes/trails, medium ring, `finisherChain` sound.
- control: violet, widest slow pulse, softer shake, `finisherControl` sound.
- bulwark: green, defensive outer ring and denser low-speed particles, `finisherBulwark` sound.

Presentation is bounded: <=18 particles, <=3 rings, <=8 trails, <=0.5s decoration TTL. The combat values remain owned by `final-form-evade-finisher.ts`.

## Phase 247~250 — SAFE Timeline Forecast
Create `src/game/endless/safe-telegraph-timeline.ts`.

Combine `SafeLaneForecast` with live `BossArenaHazard.telegraph` values. Output:
- safe-zone transition time,
- nearest threatening hazard activation time,
- decision window = min(safe transition, hazard activation),
- urgency tier: hold / prepare / move / critical,
- current and next safe targets,
- `autoMove:false`.

The Game renders one compact time-axis line near SAFE LANE and an urgency bar. It never moves the hero.

## Phase 251~254 — Mythic Tactic Reward
Create `src/game/endless/mythic-tactic-reward.ts`.

A tactic reward is granted only when SAFE LINK succeeds during a Mythic boss encounter and at least half of encounter weakpoints are already destroyed. It has no economy reward and no persistence.

Reward channels:
- 5~6 seconds of boss vulnerability, max ×1.08 damage taken.
- small Signature charge, max +3.
- tiny Flow retention extension.
- archetype-specific label/accent only; no extra entities.

Game keeps `mythicTacticBoostUntilMs` and `mythicTacticBossDamageMultiplier` as transient fields and composes the multiplier inside `endlessBossEncounterModifiers()`.

## Phase 255~258 — Foldable Thumb Zones
Create `src/game/foldable-thumb-zones.ts`.

For foldable only, derive logical left-thumb, right-thumb and hinge-neutral zones from the existing `LandscapeSafeAreaProfile`.
- left-thumb zone owns joystick starts.
- right-thumb zone owns action hit testing.
- hinge-neutral zone owns neither.
- visible action positions/radii do not change.
- per-action scale from `foldableTouchScaleMap()` remains in effect inside right-thumb zone.

Non-foldable input uses the exact existing path.

## Phase 259~262 — Raster CI Diff Summary
Create `src/game/render-raster-ci-summary.ts`.

Transform existing `RasterBaselineChangeReport` entries into deterministic human-readable CI output:
- one-line status per viewport,
- signatures and similarity numbers when changed,
- critical-cell counts,
- review token for changed baselines,
- overall PASS/REVIEW exit recommendation.

The summary never approves or writes a baseline. Exact current tree should render five PASS lines. A mutated critical HUD contract should produce REVIEW and include the approval token generated by the existing report layer.
